# SegarMart Excel Academy

Static site, no build step.

## Deploy ke Vercel (2 menit)
1. Buka https://vercel.com/new
2. Drag & drop folder ini (atau push ke GitHub lalu Import).
3. Framework Preset: **Other**. Build Command & Output Directory dikosongkan.
4. Deploy. Selesai.

Atau dari terminal: `npx vercel --prod`

Link per lesson: `https://domain-anda.vercel.app/#formula` (excel, autofill, flashfill, format, cf, dv, formula, ref, text).
